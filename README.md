# Akash L — Portfolio v2
Elite Cyber+AI theme · Next.js 14 · TypeScript · Three.js 3D Globe

## ▶ HOW TO RUN IN VS CODE

### 1. Open folder in VS Code
File → Open Folder → select `akash-portfolio`

### 2. Open terminal
Ctrl + ` (Windows/Linux) or Cmd + ` (Mac)

### 3. Install dependencies (first time only)
```
npm install
```

### 4. Start dev server
```
npm run dev
```

### 5. Open in browser
```
http://localhost:3000
```
That's it. Hot reload — changes show instantly on save.
