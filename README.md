## Run Locally

```bash
# 1. Clone
git clone https://github.com/akash-07-git-io/akash-portfolio.git
cd akash-portfolio

# 2. Install
npm install

# 3. Start dev server
npm run dev

# 4. Open browser at http://localhost:3000
```

## Deploy

Deployed on **Vercel** — auto-deploys on every push to main.

```bash
# Push changes -> Vercel rebuilds in ~30 seconds
git add .
git commit -m "your change"
git push
```
